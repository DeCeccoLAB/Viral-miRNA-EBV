# Viral-miRNA-EBV
This repository contains the official code and data for the article XXX. Here you will find all the datasets we used (as ready‑to‑use matrices) along with the R scripts required to reproduce our analyses quickly and reliably. If you have any questions, feel free to reach out to us.

PRACTICAL GUIDE TO USE THIS REPOSITORY
1)Download the data from the Data Download section.
2)Download the R scripts from the Main Article and Supplementary Materials folders.
3)Place all files into a single directory on your device and make sure to note the full path to that folder.
4)Start a new R session and run the libraries IN THE ORDER PLACED (make sure to run dplyr at the end)
5)Run the scripts, I highly suggest to run the Main article script first and the supplementary second

By following these steps, you will be able to reproduce all the analyses and figure panels presented in the article.
If you encounter any issues or have any questions, please feel free to contact us.
